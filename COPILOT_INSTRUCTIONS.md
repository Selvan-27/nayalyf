# Copilot Instructions

## Purpose
This file provides guidelines and instructions for using GitHub Copilot effectively in this project.

## General Guidelines
1. **Understand the Project Structure**: Familiarize yourself with the project structure and files before using Copilot to generate or modify code.
2. **Use Context**: Provide Copilot with sufficient context to generate accurate and relevant suggestions. For example, include comments or function signatures.
3. **Review Suggestions**: Always review the code generated by Copilot to ensure it aligns with the project requirements and coding standards.
4. **Test Changes**: After implementing changes suggested by Copilot, test the application to verify functionality.

## Specific Instructions
1. **Laravel Framework**:
   - Follow Laravel conventions for controllers, models, migrations, and views.
   - Use the `artisan` command-line tool for generating boilerplate code (e.g., `php artisan make:model`).

2. **Blade Templates**:
   - Ensure Blade syntax is used correctly in `.blade.php` files.
   - Use `@extends`, `@section`, and `@yield` for layout inheritance.

3. **Routes**:
   - Define routes in `routes/web.php` for web interfaces and `routes/api.php` for API endpoints.
   - Use appropriate HTTP verbs (GET, POST, PUT, DELETE) for route definitions.

4. **Testing**:
   - Write unit tests in `tests/Unit` and feature tests in `tests/Feature`.
   - Use PHPUnit for running tests (`php artisan test`).

5. **Version Control**:
   - Commit changes frequently with meaningful commit messages.
   - Use branches for new features or bug fixes.

## Copilot Tips
- Use comments to guide Copilot in generating specific code snippets.
- If Copilot's suggestions are not accurate, refine your input or try a different approach.
- Leverage Copilot for repetitive tasks, boilerplate code, or exploring alternative implementations.

## Troubleshooting
- If Copilot is not providing relevant suggestions, ensure your file and project context is clear.
- Check for updates to the Copilot extension and ensure it is properly configured in your IDE.
